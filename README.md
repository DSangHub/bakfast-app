# Bakfast.app

Returns without the runaround.

Interactive landing page, color-coded driver map (Mapbox-style), earnings calculator, and one-page pitch for convenient online return pickups via existing delivery drivers.

- `index.html` — Main landing page (open this)
- `bakfast-driver-map-mapbox.html` — Interactive Mapbox-style driver map
- `bakfast-driver-map.html` — Original Leaflet version
- `bakfast-pitch.md` — One-page pitch
